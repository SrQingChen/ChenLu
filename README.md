# 尘露 ChenLu — 免费无广告的下一代 Android 自动化连点器

> 尘露：如尘随行，如露精准。轻若无物，点到即达。

**尘露**是一款基于 Shizuku 特权注入 + 无障碍双引擎、深度适配小米澎湃 OS 3 交互习惯的免费开源 Android 连点器 / 自动化工具，目标是解决现有连点器「广告多、收费狠、频率低、不自由、体验糙」的通病。

## 核心特性（规划）

- 🎯 **双引擎点击**：无障碍手势（零门槛）+ Shizuku 特权注入（毫秒级、数百 Hz，不注册无障碍服务、规避游戏枚举检测）
- 🎪 **动态十字准星**：按住准星即按设定频率连点，松手即停；通过「尘露岛」悬浮胶囊 / 通知栏 / 快捷磁贴切换状态
- 📹 **录制与回放**：真实多点触控时序录制（Shizuku getevent / API 34 无障碍触摸观察），回放支持随机坐标偏移与时序抖动防检测
- 🎨 **图色触发**：MediaProjection 实时取色（10–30ms 级）+ 多点比色 / 区域找色，满足「颜色符合条件 → 执行任务」
- 🧩 **模块化架构**：对齐 Google Now in Android 的现代多模块工程，引擎层抽象、可插拔扩展
- 💠 **澎湃 OS 适配**：原生超级岛能用就用——Shizuku 焦点岛（MAA 式通道）优先、免审核媒体岛次选、传统通知栏兜底，自绘「尘露岛」胶囊为可选视觉增强；TileService 磁贴、HyperOS 保活引导
- 🆓 **完全免费，无广告，无会员**
- 📦 **GitHub 开源 + Mirror酱镜像更新**：GitHub Releases 永久免费主线路；国内可选 Mirror酱 CDN 加速（应用内检查更新，无 CDK 也能用）
